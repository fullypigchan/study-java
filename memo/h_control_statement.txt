	※ 삼항 연산자, if문, switch문의 비교
	삼항 연산자: 조건식을 1개만 사용할 때 ..
	if문: 조건식의 비교(>,<,>=,<=) 연산자를 사용하거나, 여러 개의 조건식을 논리 연산자로 연결할 때
	switch문: 하나의 변수에 여러 경우의 값이 담길 수 있고, 각 값이 같은지 비교할 때

	
▶ 반복문
		▷for문 --->내가 몇번 반복해야 하는지 먼저 계산을 하자!, 몇번 반복인지 알 때는 무조건 for문 사용!!
		          int i=0;     i<10;    i++	   (10번 반복한다고 가정. i=0일때부터 i=9일때까지가 10번 반복)
			for(초기식; 조건식; 증감식){
							실행할 문장;
			}
			
			1.초기식
			-------------------------------------------
			2.조건식(true)
			3.실행할 문장
			4.증감식

			5.조건식(true)
			6.실행할 문장
			7.증감식

			8.조건식(false)
			9.반복문 즉시 종료
		
		▷while문
			while(조건식) {

			}
		
		▷do- while문 
			do{

				} while(조건식);

▶기타 제어문
		break: 즉시 해당 중괄호 영역을 탈출한다.
				-if문 안에서 사용시, if문을 탈출하는 것이 아니라, if문을 감싸고 있는 중괄호 영역을 탈출한다.		

		continue: : 즉시 다음 반복으로 넘어간다.
				-아래의 코드를 실행하지 않기 위해서 사용한다.
