인터페이스(틀) ->약속, 규칙(틀에서 벗어날 수 없다)
		추상 클래스를 고도화시킨 문법, 상수와 추상메소드만 존재한다.
		구현은 지정한 클래스에서 진행하고, 인터페이스를 다른 클래스에 지정할 때
		implements 키워드를 사용한다. (B implements A ==> B에 추상클래스 A를 구현시킨다)

추상 클래스와 인터페이스 간의 관계
	인터페이스를 클래스에 바로 지정하면 모든 메소드에 강제성이 부여되기 때문에 전부 다 구현해야 한다
	하지만 일반적인 상황에서는 필요한 메소드를 골라서 재정의한다.(adapter라는 추상클래스를 매개자로 상속해서 오버라이딩)
	이때에는 인터페이스를 직접 지정하지 않고, 다른 클래스에 지정해서 구현해 놓는다면, 강제성이 소멸되고 이로 인해 골라서
 	재정의할 수 있게 된다. 이 때 중간에서 강제성을 없애주는 클래스를 추상 클래스로 선언하기로 하며, 추상 클래스 이름 뒤에는
	adapter를 붙여서 목적을 알려준다.

인터페이스 특징
	1. 인터페이스도 자료형(타입)이다. 인터페이스를 구현한 클래스(구현체)는 모두 인터페이스 자료형이다.
	2. 인터페이스끼리 필드를 주고 받을 때에는 extends 키워드를 사용한다.
	3. 인터페이스는 상속과 달리 여러 개를 작성하여 구현할 수 있다.
	4. default 메소드를 사용하면, 인터페이스 내부에서 일반 메소드 선언이 가능하다.(JDK 8 버전 부터)
